# Space Love Letter

A simple, cinematic, and interactive space-themed static website built with pure HTML, CSS, and JavaScript.

## Features
- 🌌 Pure CSS Animated Stars & Shooting Stars
- 💎 Glassmorphism UI Design
- 🚨 Shake animation and funny error messages for incorrect inputs
- 🎵 Procedurally generated web audio chime (no external audio files needed!)
- 📱 Fully Responsive
- ⚡ Lightweight and Fast (0 dependencies)

## How It Works
1. Visitors are greeted with a space-themed identity verification card.
2. If the user enters the name "habiba" or "Habiba":
   - A beautiful success popup will fade in.
   - A sweet melody will play.
3. If the user enters anything else:
   - The card will shake to indicate access denied.
   - A funny error message will appear (e.g., "Nah bro... wrong universe :/").

## Deployment Instructions

This project is 100% static and requires no build steps. It is completely ready to be deployed instantly.

### Deploy to Netlify (Fastest)
1. Go to [Netlify Drop](https://app.netlify.com/drop).
2. Drag and drop this entire project folder into the Netlify drop zone.
3. Your website will be live in seconds!

### Deploy to GitHub Pages
1. Create a new repository on GitHub.
2. Upload all the files from this folder to the repository.
3. Go to your repository **Settings** > **Pages**.
4. Under the **Source** drop-down, select the `main` (or `master`) branch.
5. Click **Save**. Your website will be available at `https://[your-username].github.io/[repo-name]`.
